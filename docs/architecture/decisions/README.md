# Architecture decision records

**Owner:** Solution Architect Agent. **Reviewers:** Affected domain owners and Security. **Status:** Planning convention. **Version:** 0.1. **Date:** 2026-10-14.

Create one future record per significant architecture decision, using a stable ADR identifier and descriptive filename. A record includes title, status, date, owner, reviewers, context, constraints, options, selected option, rationale, consequences, affected requirements/contracts, and superseded records.

Record the fixture-versus-service decision before implementation, then any framework/runtime/storage/hosting choices. Do not write an Accepted decision before its review. The project-level open decisions are tracked in [the register](../../governance/registers.md).
