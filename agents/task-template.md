# Agent assignment and handoff template

Copy this structure into an assignment or work-item document. Replace every placeholder with task-specific information.

## Assignment

- Task ID and title:
- Current user-authorized objective:
- Assigned canonical role / compatibility name:
- Orchestrator and reviewers:
- Documentation-only, read-only review or implementation:
- Exact writable files:
- Read-only inputs and contract versions:
- Shared-file owner:
- Dependencies / expected upstream handoff:
- Observable acceptance criteria:
- Explicit exclusions and decisions still open:
- Verification required:
- Runtime/server/port ownership if relevant:

## Handoff

- Outcome and practical behavior:
- Files changed, or findings with paths and reproduction:
- API/schema/data/metric decisions:
- Commands actually executed and results:
- Evidence attributed to another reviewer:
- Checks not run and why:
- Assumptions, synthetic/preview limitations and unresolved issues:
- Downstream role / integration action:
- Ready for integration, requires revision, or waiting on a specific dependency:

Do not fill a passing status from a historical count. Do not claim a role's mere presence in the catalogue proves that it performed a task.
