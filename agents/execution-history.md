# Agent names and delivery history

This is a reconstruction of the local team from repository charters and observed collaboration assignments. It is not an export of hidden prompts, model state, session transcripts or all original execution logs.

The role instructions are reconstructed reusable guides, not claimed byte-for-byte copies of the original task messages. Current runtime agents must be started or assigned anew; these files do not reconnect old sessions.
